# JerryTunes (Koda Inspired)

A high-performance, modern music streaming and offline playback application built with **React Native**, **Expo SDK 58**, and **TypeScript**, inspired by iKoda.

## Quick Start Tomorrow

To resume development or testing:

1. **Start Backend Server:**
   - Double-click `start_server.bat` OR run:
     ```bash
     cd server && node --dns-result-order=ipv4first --max-http-header-size=80000 index.js
     ```
2. **Start Expo Metro Bundler:**
   - Double-click `start_app.bat` OR run:
     ```bash
     npx expo start --go -c
     ```
